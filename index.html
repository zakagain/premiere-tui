Scaffold Premiere Pro Projects Instantly.

A lightweight PowerShell CLI tool that copies your master template folder, renames the .prproj to match the project name, and boots Adobe Premiere in one command.

Configuration

Three variables. That is the whole setup.

premiere-tui keeps every setting in one small config file. Point it at a template, a destination, and the project file to start from — then leave it alone.

$TemplateFolder

Define your master directory structure.

Example

C:\Templates\Premiere Master

$ProjectsParentFolder

Point to your active storage or NVMe scratch drive.

Example

D:\Premiere Projects

$TemplateProjectFile

Pick which .prproj in the template is renamed for each project.

Example

Master_Template.prproj
